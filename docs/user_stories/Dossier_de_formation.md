# User Stories — Dossier de formation

## Apprentice

### 1. View the dossier and projects

**As an apprentice, I want to see a list of my projects in my Dossier de formation, so that I have an overview of the work I have completed.**

When I open the Dossier de formation section, I see a list of all projects I have added.

For each project, I can open its detail page. On the project page, I can see all the information saved for that project, as well as the PDF generated from that information.

From the main Dossier de formation page, I can also create a new project.

### 2. Create a project

**As an apprentice, I want to create a new project in my Dossier de formation, so that I can record the work I completed and the CFC competences related to it.**

From the main Dossier de formation page, I click **"Create project"**. A screen divided into two sections opens.

The left section contains the project form with the following fields:

- **Title** — the name of the project.
- **Organisation** — the organisation for which or within which the project was completed.
- **Start date / End date** — the dates when the project started and finished.
- **Description** — a detailed description of what was done as part of the project.
- **Technologies** — the technologies used during the project.
- **Role** — the apprentice's role in the project.
- **GitHub link** — a direct link to the project's code.
- **Live demo link** — a link to a working demonstration of the project, if available.
- **Competences** — a selection of competences from a predefined CFC list.

For each selected competence, the apprentice indicates whether it was:

- **Mobilized** — an existing competence was applied during the project.
- **Developed** — the competence was learned, developed, or improved during the project.

The apprentice can also add **one or more screenshots** of the project.

### 3. Preview the project PDF

**As an apprentice, I want to see a preview of my project PDF while creating it, so that I can see what the final document will look like.**

The right section of the screen displays a preview of the current project's PDF.

Where technically possible, the PDF is updated dynamically as the apprentice changes the information in the form, so that the preview always reflects the latest data.

Each project has **its own PDF**: one project corresponds to one PDF document.

### 4. Save or cancel a project

**As an apprentice, I want to save or cancel the creation of a project, so that I can control the changes made to my Dossier de formation.**

At the bottom of the screen, the following actions are available:

- **Cancel** — cancels the project creation, clears the entered data, and returns the apprentice to the main Dossier de formation page.
- **Save** — saves the project data to the database and returns the apprentice to the main Dossier de formation page.
- **Export** — allows the apprentice to save the current project's PDF to their device.

After saving, the project appears in the apprentice's project list.

### 5. View a project

**As an apprentice, I want to open an individual project and see all its related information, so that I can review the contents of my dossier.**

When opening a project, the apprentice can see all saved information, including:

- project information;
- description;
- organisation;
- dates;
- technologies;
- role;
- links;
- selected competences and their status;
- added screenshots.

The project's PDF is displayed alongside the project information and can be exported to the apprentice's device.

### 6. Edit a project

**As an apprentice, I want to edit an existing project, so that I can correct mistakes and keep the information in my Dossier de formation up to date.**

The apprentice can open a saved project and modify its information, including the description, dates, technologies, role, links, competences, and screenshots.

After the information is changed, the project's PDF is also updated to reflect the latest data.

### 7. Delete a project

**As an apprentice, I want to delete a project from my Dossier de formation, so that I can remove a project that should no longer be part of my dossier.**

The apprentice can delete an existing project. After deletion, the project no longer appears in the project list.

### 8. Export a project PDF

**As an apprentice, I want to export my project PDF, so that I can save or share the document outside the application.**

From the project page, the apprentice can click **"Export"** and save the project's PDF to their device.

The exported PDF contains the latest project information stored in the system and shown in the PDF preview.
