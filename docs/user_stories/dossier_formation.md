# User stories — Dossier de formation

Apprentice-only feature — no coach role in this flow.

## Apprentice

1. **As an apprentice, I want to add a new project to my dossier, so that I can record what I built and which competences it covers.**
   After finishing a project, I open the dossier section and fill in a form: title, the organisation I worked for, when I started and finished, 
what I built, what technologies I used, and what my role was on it. I also attach a screenshot or a link to a live demo, and either a link to the code or a short note explaining why I can't share it. 
This is the same information the official CFC brief requires — I'm not writing a report from scratch each time, just filling in the same structure.

2. **As an apprentice, I want to pick competences from a fixed list when adding a project, so that my dossier stays consistent with the official codes.**
   Instead of typing a competence code by hand (and risking a typo like B601 instead of B60), I check them off a list, and for each one I mark whether 
I "mobilized" it (used something I already knew) or "developed" it (learned/improved it on this project). That distinction is exactly what the CFC plan de formation asks for.

3. **As an apprentice, I want to edit or delete a project I added, so that I can fix mistakes or remove something that shouldn't be there.**
   If I mistyped something, picked the wrong competence, or added a project that turned out not to belong, I can go back into it and change or remove it. The dossier isn't locked once submitted — 
it's mine to keep accurate as I go.

4. **As an apprentice, I want to see my whole dossier as one page, with my personal and formation info at the top, so that I have a full overview of everything I've done.**
   Opening the dossier view shows my name, my formation title and dates, and a summary list of every project — 
followed by the full detail of each one. It's the same page whether I'm checking my own progress or preparing to show it to someone else; nothing needs to be separately compiled or reformatted.

5. **As an apprentice, I want to export my dossier to PDF, so that I can hand it to my formateur or keep a copy outside the app.**
   One button turns the dossier view into a PDF I can download or print, using the same information that's already on screen — 
always current, so I'm never handing over an out-of-date version I forgot to regenerate.
