# Grade Tree — Informaticienne/Informaticien CFC (computerr.txt)

Source: Ordonnance du SEFRI sur la formation professionnelle initiale d'informaticienne/informaticien CFC, Art. 18-19.

```
Note globale (≥ 4 requis)
├── Travail pratique (TPI) — 40%                          (≥ 4 requis)
│   ├── Exécution et résultat du travail — 50%
│   ├── Documentation — 20%
│   └── Présentation et entretien professionnel — 30%
├── Culture générale — 20%
├── Compétences en informatique (note d'expérience) — 30%  (≥ 4 requis)
│   ├── Notes école professionnelle (modules) — 80%
│   └── Notes cours interentreprises — 20%
└── Compétences de base élargies (note d'expérience) — 10%
    └── Moyenne des 8 notes semestrielles (compétences de base élargies)
```
