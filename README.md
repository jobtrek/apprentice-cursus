# Apprentice Cursus

## Description

Une application de suivi de notes permettant aux coachs, aux formateurs et aux apprentis d'avoir un suivi et une communication efficace des notes. Basée sur les conventions déjà mise en place pour la transmissions des notes.

## Project set up

**W.I.P**

## Stack

Vue
Inertia
Laravel
Postgres

## Features

### Grade transmission automation

Apprentices will be able to drag and drop their test PDF in the app. A notification will then be sent to both their trainers and assigned coaches.

### Grade dashboard

The grades will be accessible in a dashboard, giving apprentice an overview of their own grades and trainers / coaches an overview of the grades of apprentice they're responsible of.

### Grades comment

Trainers and coaches will be able to add commentaries to apprentice grades. They also will be able to download the PDF of the test
